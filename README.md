# Cardápio Digital — Frontend Demo

Versão demonstrativa do frontend de um sistema de cardápio digital para restaurantes.

O projeto foi criado para explorar uma experiência em que o cliente acessa o cardápio pelo celular, visualiza os produtos, adiciona itens ao pedido, inclui observações e acompanha o fluxo do pedido pela interface.

> **Status:** 🚧 Em desenvolvimento  
> Este repositório contém apenas uma versão pública e reduzida para demonstração. O projeto completo possui funcionalidades e etapas adicionais que não estão disponibilizadas aqui.

## Funcionalidades demonstradas

- Navegação por categorias
- Exibição de produtos, descrições e preços
- Adição de itens ao pedido
- Campo de observação por item
- Visualização e edição do pedido
- Simulação de envio e acompanhamento
- Interface responsiva para dispositivos móveis

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub
- GitHub Pages

## Objetivo

Projeto desenvolvido como parte do meu portfólio e dos meus estudos em Análise e Desenvolvimento de Sistemas, com foco em desenvolvimento web, responsividade, lógica de programação e experiência do usuário.

O objetivo da aplicação é simular uma solução em que o cliente possa realizar o pedido diretamente pelo celular, reduzindo etapas do atendimento e tornando a experiência mais prática.

## Sobre o projeto

Esta versão representa apenas a interface pública de demonstração do sistema.

O projeto completo foi pensado para incluir funcionalidades adicionais, como gerenciamento de pedidos, painel do restaurante, controle de status e outras etapas que não estão presentes neste repositório público.

## Observação

Esta é uma demonstração de frontend. Não representa o sistema completo nem inclui backend, banco de dados, autenticação ou integrações de produção.
